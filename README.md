# Week 7 Lecture Exercises

Complete the TODO in each `main.cpp`. Both exercises use C++17 and a C++ compiler
such as `g++`.

From the repository root, run:

```sh
bash CRAII/run_test.sh
bash CSmartPointer/run_test.sh
```

The tests compile and run each exercise in a temporary directory. Unfinished
starters are expected to fail. To run both tests and see the same two-point
summary as GitHub Actions, run:

```sh
python3 .github/scripts/grade.py
```

The grader awards one point per exercise and writes `grading-results.json`
locally. Submit changes to the `main.cpp` files only; the tests and grading
workflow are part of the assignment.
